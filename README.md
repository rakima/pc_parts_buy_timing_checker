# 時期判定官 ヴィクトル

PCパーツの商品ページから現在価格を取得し、SQLiteに蓄積した過去価格と比較して「今が買い時か」を判定するデスクトップツールです。価格を調査するたびに、判定結果に応じた時期判定官ヴィクトルの表情とセリフが表示されます。

## 主な機能

- 商品名、カテゴリ、URL、取得サイト、有効状態の登録・編集・削除
- ユーザー操作による価格調査（常時監視は行いません）
- SQLiteへの取得価格と取得日時の保存
- 直近30日平均との比較による買い時判定
- 調査中を含む6段階のヴィクトル画像とセリフ
- 商品ごとの価格履歴一覧
- 取得失敗を含む操作ログのローテーション保存
- ワーカースレッドによる非同期取得

## 必要環境

- Python 3.11以降（`tkinter`を含むPython環境）
- インターネット接続

外部Pythonパッケージは使用しません。リポジトリを取得後、そのまま起動できます。

## 起動方法

```powershell
python main.py
```

初回起動時に `data/victor.db`、`config/settings.json`、`logs/victor.log` が自動作成されます。

## 商品登録と価格調査

1. `商品登録` を押します。
2. 商品名、カテゴリ、商品URL、取得サイトを入力して保存します。
3. 一覧から商品を選択し、`価格を調査する` を押します。
4. 調査完了後、現在価格、30日平均、平均との差、最安値、判定を確認します。

取得サイトには識別用の名称を入力します。MVPではすべてのサイトに汎用取得処理を使用します。商品ページ内に `product:price:amount` メタ情報、またはJSON-LDの `price` があるページが対象です。

## 判定ロジック

今回の取得価格を含めず、直近30日以内の履歴平均と比較します。最低3件、かつ最古と最新の履歴が7日以上離れていない場合は「データ不足」と表示します。

| 平均との差 | 判定 |
| --- | --- |
| +5%以上 | 時期が悪い |
| -5%より高く+5%未満 | 微妙 |
| -10%より高く-5%以下 | 悪くない |
| -15%より高く-10%以下 | 買い時 |
| -15%以下 | 絶好の買い時 |

期間、必要履歴数、各境界値は `config/settings.json` で変更できます。

## 対応サイトと注意事項

MVPは標準的な構造化価格情報を公開するEC商品ページに対応します。Amazon、ドスパラ、ツクモ、パソコン工房などのサイト専用アダプターは未実装です。ログイン、JavaScript実行、CAPTCHA、アクセス制限が必要なページは取得できません。

サイトの利用規約を確認して利用してください。HTML構造の変更により取得できなくなる場合があります。本ツールは手動操作時に1回だけアクセスし、常時監視や自動巡回は行いません。価格取得失敗は他の商品やアプリ全体を停止させず、`logs/victor.log` に商品、URL、日時、エラーを記録します。

**本ツールの買い時判定は価格履歴を元にした参考情報であり、将来の価格を保証するものではありません。** 購入判断は送料、在庫、販売元、保証なども確認した上で行ってください。

## データ保存先

- 商品・価格履歴: `data/victor.db`
- 設定: `config/settings.json`
- ログ: `logs/victor.log`
- キャラクター画像: `assets/images/`

画像が存在しない、または読み込めない場合はテキストのプレースホルダーを表示します。
